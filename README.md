# Assistenten-Mailer – OAuth-Informationsseiten

Statische öffentliche Informationsseiten für die Google-OAuth-Konfiguration des privaten Assistenten-Mailers.

Die produktive Zieladresse ist:

`https://assistent.apotheke-dortmund.de`

Enthalten sind App-Homepage, Datenschutzerklärung, Nutzungsbedingungen, robots.txt und die GitHub-Pages-CNAME-Datei.

Es werden keine OAuth-Secrets, Tokens oder Google-Nutzerdaten in diesem Repository gespeichert.
